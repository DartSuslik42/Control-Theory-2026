Источник задания: [`../../Assignment/Assignment2.pdf`](../../Assignment/Assignment2.pdf) и [`../../Assignment/Assignment2.ipynb`](../../Assignment/Assignment2.ipynb).

## Исходная система

Пусть `n` — номер студента в списке группы. Задана система в пространстве состояний

```text
dx/dt = A x + B u,
y     = C x,

    [ 0     0       1      0 ]       [ 0 ]
A = [ 0     0       0      1 ],  B = [ 0 ],  C = [ 1  1  0  0 ].
    [ n    -2    -10/n    -2 ]       [-1 ]
    [-5  -n/10      0     -3 ]       [ 1 ]
```

Перед вычислениями нужно узнать своё значение `n` у преподавателя/ассистента.
